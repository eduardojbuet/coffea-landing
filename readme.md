# Coffea Landing Page

Landing page estática desarrollada para la cafetería Coffea en el marco de la materia Diseño UX-UI (Licenciatura en Sistemas de Información, UADER FCyT)[cite: 1, 6].

## Stack Tecnológico
- HTML5 Semántico[cite: 1]
- CSS3 puro (Variables CSS, Custom Properties, @layer, Flexbox, Grid, Scroll-snap)[cite: 1, 6]
- Sin JavaScript (interacciones resueltas de manera nativa mediante CSS)[cite: 1, 9]

## Estructura del Proyecto
- `index.html`: Estructura principal de la página.
- `404.html`: Página de error para Netlify[cite: 7].
- `css/`: Capas organizadas (tokens, base, layout, componentes y responsive)[cite: 6, 7].
- `assets/`: Imágenes optimizadas y recursos gráficos[cite: 7, 12].

## Despliegue
Sitio estático configurado para despliegue continuo en **Netlify** mediante el archivo de configuración `netlify.toml`[cite: 11].
